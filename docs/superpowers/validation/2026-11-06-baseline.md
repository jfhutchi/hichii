The bundled Qt package lacks Qt6Test, so this baseline builds the command-line
frontend and the core tests. It does not establish that the GUI builds.

One local source-specific warning exception is necessary with Clang 23:
`-Wno-error=unused-but-set-global` for the preexisting unused `expected_callback`
in `src/tests/core/core_timing.cpp:22`. A deferred source property in the ignored
`.local-tools/baseline-warning.cmake` adds it through `CMAKE_PROJECT_INCLUDE`.
Production warnings-as-errors stay enabled. No tracked source was edited to
silence the warning. The full build log retains the warning.

An earlier attempt with VS2026 MSVC 14.51 headers failed in that standard
library's vectorized ranges-find implementation for `StorageBufferAddr`; the
supported VS2022 headers avoid that baseline toolchain failure.
